# Derse Bi' Mola - Agent Çalışma Kuralları

## Otomatik Git Yükleme (Auto Push to GitHub)
- Kod üzerinde yapılan geliştirme, hata düzeltmesi veya yeni özellik ekleme işlemleri tamamlandığında ve sözdizimi doğrulandığında, kullanıcıya sormadan **otomatik olarak** `git add`, `git commit` ve `git push origin main` komutlarını çalıştır.
- Commit mesajlarını Türkçe ve açıklayıcı convention'lara uygun yaz (Örn: `feat: ...`, `fix: ...`).
